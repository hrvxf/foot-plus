# Partnerships

Layer 3 reference. Local partners help patients and help Foot+ rank on Google through genuine links back to the site. Read this before adding a partner, changing `/partners`, or drafting outreach.

## Rules

- Only list a partner once both sides have agreed. Never present a relationship as confirmed, or a backlink as live, until it is.
- Partner data lives in `app/lib/partners.ts`; the `/partners` page and the location pages' partner strip read from it. The strip stays hidden for a location with no partners.
- Record every contact in the tracker.

## Files

| File | What it is |
|---|---|
| `local-partnership-tracker.csv` | Every organisation contacted, status, and whether links exist both ways. Keep up to date |
| `local-partnership-outreach.md` | Email templates by partner type |
| `severn-physiotherapy-partnership-checklist.md` | Checklist for the first partner; reuse it as the pattern for new ones |
