# Advice measurement plan

## Google Search Console

Use a Page URL filter containing `https://foot-plus.co.uk/advice/`. Track impressions, clicks, CTR, average position, queries, countries, devices and indexing status by advice URL.

## GA4 measures

Track advice landing sessions, engaged sessions, `advice_article_view`, `advice_cta_click`, `advice_service_link_click`, `advice_related_article_click`, `booking_click` where configured, phone clicks, email clicks, source/medium, organic landing pages and ChatGPT referrals.

## Recommended periods

Review the first 28 days, compare with the previous 28 days where meaningful, then review the first 90 days. Use year-on-year only when enough historical data exists. Do not claim improvement before data exists.

## GA4 configuration to complete manually

Mark lead-intent events such as `booking_click`, `phone_click` and `email_click` as key events if appropriate. Do not mark `advice_article_view` as a conversion. Build comparisons/audiences for Advice visitors, Organic advice visitors, ChatGPT-referred visitors, Advice visitors who clicked booking and Advice visitors who clicked phone.
